# ロイロノート 提出箱チェッカー

ロイロノートスクール（ブラウザ版）の提出箱を複数チェックし、**未提出者一覧**を教科・提出箱別に作成するツールです。

## 機能

- 複数の教科・提出箱を一括チェック
- 未提出者を教科・提出箱別に整理して表示
- Excel ファイルへの出力（フィルタ・ソート対応）
- 2つの動作モード:
  - **ブラウザモード**: Selenium でロイロノートを自動操作
  - **Excel モード**: ダウンロード済みの提出状況 Excel を処理

## セットアップ

### 1. Python パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 設定ファイルの編集

`config.yaml` を開き、以下を設定してください:

```yaml
login:
  school_id: "あなたの学校ID"
  username: "教員ユーザー名"
  password: "パスワード"

targets:
  - subject: "数学"
    class_name: "1年A組"
    submission_boxes: []  # 空 = 全提出箱チェック
```

## 使い方

### モード1: ブラウザ自動操作（推奨）

```bash
python main.py
```

ブラウザが自動で起動し、ロイロノートにログインして提出箱をチェックします。

### モード2: Excel ファイル処理

ロイロノートの管理ページから提出状況 Excel をダウンロード済みの場合:

```bash
# 1. downloads/ フォルダに Excel ファイルを配置
# 2. 実行
python main.py --excel-mode
```

### 出力形式の指定

```bash
python main.py --output console   # コンソール表示のみ
python main.py --output excel     # Excel 出力のみ
python main.py --output both      # 両方（デフォルト）
```

- **シート2「詳細データ」**: フィルタ・ソート可能な全データ一覧

## ブラウザモードのセレクタ調整

ロイロノートの画面構成が更新された場合、ブラウザモードのセレクタ調整が必要になることがあります。

1. Chrome で `https://loilonote.app` にログイン
2. `F12` キーで DevTools を開く
3. 提出箱画面の要素を右クリック → 「検証」で CSS セレクタを確認
4. `loilo_checker/browser.py` のセレクタ定数を更新

```python
# 例: ログインフォームのセレクタを変更
SELECTOR_USERNAME_INPUT = 'input#your-actual-selector'
```

## ファイル構成

```
teishutu/
├── main.py                      # メインスクリプト
├── config.yaml                  # 設定ファイル
├── requirements.txt             # Python 依存パッケージ
├── README.md                    # このファイル
└── loilo_checker/
    ├── __init__.py
    ├── browser.py               # Selenium ブラウザ自動操作
    ├── excel_processor.py       # Excel ファイル処理
    └── reporter.py              # レポート生成・出力
```

## 注意事項

- ブラウザモードはロイロノートの画面構成（DOM 構造）に依存します。ロイロノートのアップデートでセレクタの調整が必要になる場合があります。
- ログイン情報は `config.yaml` に平文で保存されます。ファイルの管理にご注意ください。
- 自動操作がロイロノートの利用規約に抵触しないか、事前にご確認ください。
